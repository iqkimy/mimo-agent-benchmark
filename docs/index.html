Why This Exists

Agent Workloads Break Differently

Standard LLM benchmarks don't capture what happens when MiMo-V2.5 runs in real agent frameworks — tool-calling loops, multi-agent pipelines, RAG chains.

🧠

Context Degradation

Model loses track of earlier tool results as context grows past 8K tokens.

⚠ Silent wrong answers, missed instructions
🔧

Tool Routing Failures

Model calls wrong tools or passes malformed arguments at scale.

⚠ Broken pipelines, retry storms
🤖

Parallel Agent Slowdown

Multi-agent systems see 3-5x latency increase vs single-agent.

⚠ Unacceptable UX in production
📚

Retrieval Grounding Drift

Model hallucinates answers instead of citing retrieved documents.

⚠ Unreliable RAG outputs
💸

Token Inefficiency

Model generates verbose reasoning for simple tool calls.

⚠ Higher cost, slower throughput
How It Works

Hypothesis → Verdict Pipeline

Every benchmark starts with a testable claim. The results come entirely from live MiMo API calls.

H

Hypothesis

Define testable claim

W

Workload

Structured test input

E

Execute

Real MiMo API calls

R

Result

Metrics collected

V

Verdict

PASS / FAIL

hypothesis-example.json
// Example: Hypothesis h2 — Tool Routing "Hypothesis:" "MiMo-V2.5 retains >90% tool-calling accuracy with 50+ tools in context" ↓ "Workload:" workloads/stress/tool-avalanche.json (50 tools, 10 test cases) ↓ "Harness:" Runs each case 5×, collects timing + accuracy metrics ↓ "Result:" 93.2% accuracy @ 284ms avg latency → PASS ✓

Test Arsenal

9 Workloads Across 3 Categories

From stress tests that push limits to realistic production scenarios.

STRESS Push to the Limit

  • 📄 context-flood.json — Context size 1K → 32K tokens
  • 📄 tool-avalanche.json — 5 to 100 tools available
  • 📄 parallel-agents.json — 1 to 8 concurrent instances
  • 📄 nested-tools.json — 10-level deep chained calls
  • 📄 adversarial-prompt.json — Prompt injection resistance

REALISTIC Production Scenarios

  • 📄 code-refactor-session.json — Multi-file refactoring
  • 📄 data-analysis-pipeline.json — Sequential processing
  • 📄 customer-support-chain.json — Multi-turn + KB retrieval
  • 📄 research-assistant-flow.json — Search + summarize + cite

REFERENCE Cross-Model Baselines

  • 📄 gpt4o-baseline.json — GPT-4o reference results
  • 📄 claude35-baseline.json — Claude 3.5 Sonnet reference results
  • 📄 qwen-max-baseline.json — Qwen-Max reference results
