Why This Exists

Standard LLM benchmarks test single-shot Q&A. But Agent frameworks generate completely different workloads — and MiMo-V2.5's performance under those conditions was unknown.

📉 Context Degradation

Model loses track of earlier tool results as context grows past 8K tokens. Silent wrong answers, missed instructions.

🔧 Tool Routing Failures

Model calls wrong tools or passes malformed arguments at scale. Broken pipelines, retry storms.

🐢 Parallel Agent Slowdown

Multi-agent systems see 3-5x latency increase vs single-agent. Unacceptable UX in production.

📚 RAG Grounding Drift

Model hallucinates answers instead of citing retrieved documents. Unreliable RAG outputs.

💸 Token Inefficiency

Model generates verbose reasoning for simple tool calls. Higher cost, slower throughput.

How It Works

Hypotheses define what to test — results come entirely from live MiMo API calls. No simulated data, no assumptions.
